A solid 22px tag holding one letter, filled with the data hue of the object it names: `T` tangente (`tangent`), `N` normal (`normal`), `B` binormal (`binormal`), `r` curva (`curve`), `P` ponto ativo (`point`), `E` evoluta (`evolute`), `I` involuta (`involute`).

- The letter is `on-data`, which holds 4.5:1 on every hue in both themes.
- One hue per object, everywhere: the tag, the toggle dot, the 3D trace and the legend must agree. Never reuse a hue for something else.
- The set `{T, N, B}` is separated by lightness and hue (green, vermilion, reddish purple), so it survives red-green colour blindness; the letter is always present as the second cue.
